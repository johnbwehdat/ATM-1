# ATM Simulator

A simple ATM program that lets users check balance, deposit, and withdraw money.

## What problem does it solve?
It simulates basic banking operations and helps me practice loops and conditionals.

## What I learned
- While loops for repeated menus
- if/elif/else for user choices
- Using break to exit a loop
- Basic input validation

## How to run it
1. Clone the repo
2. Run `python atm.py`
3. Choose options 1-4 from the menu

## What I'd improve next
- Add a transfer feature between accounts
- Save balance to a file so it persists between sessions
